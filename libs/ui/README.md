# UI libraries

Reusable frontend packages. `core` exposes the starter component library through `@outcometrik/ui`.

`api` exposes the shared frontend API SDK through `@outcometrik/api`. Endpoint clients consume it to standardize transport, errors, and wire types.

`modules/` contains domain libraries, each encapsulating related features under `src/features/`. See [module conventions](modules/README.md).
