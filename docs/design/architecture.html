Outcometrik Architecture

Pilot runtime · Django modular monolith · versioned evidence and immutable publications

Colors: cyan = client · green = backend · rose = authorization · violet = storage · slate = operations. Solid arrows = synchronous calls/I/O; dashed arrows = telemetry or scheduled backup. Internal modules share one Django deployment.

One deployable backend

  • • Python modules call scoped service facades.
  • • PostgreSQL is the shared transaction boundary.
  • • React and API share one HTTPS origin.
  • • No queue or shared cache in the pilot.

Reproducible publication

  • • Capture actual operands, not only a hash.
  • • Compute from a frozen manifest.
  • • Recheck live revisions before publishing.
  • • Corrections preserve historical evidence.

Honest pilot limits

  • • One host and DB primary remain SPOFs.
  • • Daily encrypted off-host backups.
  • • Five-second scoring target needs measurement.
  • • Async workers follow measured bottlenecks.

Publication and correction protocol

Ordered workflow stages inside Django; these are not separately deployed services.
